Starlight Grove is a top-down 2D arena shooter: defend the Heartseed tree through 10 waves, beat the Hollow Warden boss, and spend gold on upgrades between waves. Plain JavaScript and Canvas, no network, with synthesized WebAudio sound effects and generative music.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
